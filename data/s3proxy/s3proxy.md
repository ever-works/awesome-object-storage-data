## Overview

s3proxy is an open-source proxy that presents an S3 API backed by a local file system or by other cloud stores, including Azure Blob and Google Cloud Storage. It is a common way to give non-S3 backends an S3 face.

## Features

- Open-source S3 proxy
- Presents S3 API backed by local file system
- Supports Azure Blob as a backend
- Supports Google Cloud Storage as a backend
- Gives non-S3 backends an S3 interface
- Self-hosted deployment

## Deployment

Self-hosted. Endpoint format: `http://<your-proxy-host>:80`. Addressing: path-style.
