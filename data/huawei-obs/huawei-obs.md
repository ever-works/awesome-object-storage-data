## Overview

Huawei OBS (Object Storage Service) is a versatile cloud object storage service that allows users to store unlimited amounts of unstructured data securely and efficiently.

## Key Features

- Multipart Upload
- Logging And Monitoring
- Data Encryption
- Lifecycle Management
- Event Notifications
- Object Lock
- Static Website Hosting
- Scalability

## Deployment

Huawei OBS is a cloud service provided by Huawei Cloud.
