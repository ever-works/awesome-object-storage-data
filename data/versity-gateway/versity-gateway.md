## Overview

Versity Gateway is an open-source S3 gateway with pluggable backends. It allows you to put an S3 API in front of a POSIX file system or other stores, making it useful for exposing existing file storage, including tape-backed archives, over S3.

## Features

- Open-source S3 gateway
- Pluggable backends
- S3-compatible API
- Exposes POSIX file systems over S3
- Supports tape-backed archives over S3
- Self-hosted deployment

## Deployment

Self-hosted. Endpoint format: `http://<your-gateway-host>:7070`. Addressing: path-style.
