## Overview

STRG is an S3-compatible object storage service offering full S3 API compatibility with unlimited free egress. Versioning is always on, so old object versions remain billed until explicitly removed. Storage is priced at $0.0068/GB/mo.

## Pricing

Paid. Storage at $0.0068/GB/mo. Egress is unlimited and free.

## Features

- Full S3 compatibility
- Versioning always on
- Object lock
- Unlimited free egress
- Max object size: not published
