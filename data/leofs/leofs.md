## Overview

LeoFS is an open-source distributed object store with an S3-compatible interface. It is designed for distributed object storage deployments.

## Features

- Open-source distributed object store
- S3-compatible interface
- Distributed architecture
- Self-hosted deployment

## Deployment

Self-hosted. Endpoint format: your LeoFS gateway address (your own deployment). Addressing: path-style.
