## Overview

Impossible Cloud is an EU-focused object storage service with full S3 compatibility. It offers object lock, versioning, and genuinely unlimited free egress without reasonable-use restrictions. Storage is priced at $0.006/GB/mo.

## Pricing

Paid. Storage at $0.006/GB/mo. Egress is free.

## Features

- Full S3 compatibility
- Object lock
- Versioning
- Unlimited free egress
- EU-focused
- Max object size: 5 TB
