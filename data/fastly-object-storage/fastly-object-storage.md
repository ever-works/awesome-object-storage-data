## Overview

Fastly Object Storage is an S3-compatible object storage service integrated with Fastly's CDN network. It offers full S3 API compatibility but does not support object lock or versioning. Egress is included with CDN usage.

## Pricing

Paid. Storage at $0.012/GB/mo. Egress is included with CDN.

## Features

- Full S3 compatibility
- No object lock
- No versioning
- Egress included with CDN
- Max object size: 5 TB
- Newer product with fewer features than mature providers
