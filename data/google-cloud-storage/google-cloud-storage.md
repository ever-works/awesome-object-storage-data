## Overview

Google Cloud Storage (GCS) is a scalable, fully-managed object storage service from Google Cloud Platform. It provides S3 interoperability through its interoperable access API and supports object lock, versioning, and multiple storage classes.

## Pricing

Paid. Storage starts at $0.020/GB/mo for standard tier. Egress is $0.12/GB after the 100 GB/mo free allowance.

## Features

- S3 interoperability API
- Four storage tiers
- Object lock / WORM
- Versioning
- 100 GB/mo free egress
- Max object size: 5 TB
