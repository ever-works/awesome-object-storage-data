## Overview

Hetzner Object Storage is an EU-based object storage service offered by Hetzner Online. It provides full S3 compatibility with object lock and versioning support. Storage is priced at $0.0052/GB/mo with 1 TB of internal transfer included.

## Pricing

Paid. Storage at $0.0052/GB/mo. Egress at $0.01/GB. 1 TB internal transfer included.

## Features

- Full S3 compatibility
- Object lock
- Versioning
- 1 TB internal transfer included
- EU-only regions
- Max object size: 5 TB
