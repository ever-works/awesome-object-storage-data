## Overview

anon.li Drop is a zero-knowledge end-to-end encrypted file sharing service. Files are encrypted client-side using AES-256-GCM before upload, and the server has zero access to the data.

## Features

- Client-side AES-256-GCM encryption
- Zero server-side data access
- Free uploads for files up to 5GB
- Maximum expiry of 3 days
- Accessible via website, CLI, or API

## Pricing

Free tier available with file size limit of 5GB and max 3-day expiry.
