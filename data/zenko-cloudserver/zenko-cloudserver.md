## Overview

Zenko CloudServer is an implementation of the Amazon S3 protocol on the front-end, with backend storage capabilities that connect to multiple clouds including Azure and Google Cloud. It provides an S3-compatible interface for multi-cloud storage.

## Deployment

Self-hosted via Docker. Built with Node.js.
