## Overview

Linode Object Storage (part of Akamai Cloud) provides S3-compatible object storage with full S3 API support. It supports versioning but does not support object lock. Objects are capped at 5 GB maximum size, which limits multipart uploads.

## Pricing

Paid. Storage at $0.020/GB/mo. Egress at $0.005/GB after transfer pool.

## Features

- Full S3 compatibility
- Versioning
- No object lock
- Max object size: 5 GB (no multipart above that)
- Transfer pool for egress
