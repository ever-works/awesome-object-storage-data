## Overview

RustFS is an open-source, S3-compatible high-performance object storage system written in Rust. It supports migration and coexistence with other S3-compatible platforms such as MinIO and Ceph.

## Key Features

- S3-compatible object storage API
- High-performance object storage
- Migration support for other S3-compatible platforms
- Coexistence with MinIO and Ceph
- Written in Rust
