## Overview

Azure Blob Storage is Microsoft's object storage service on the Azure cloud platform. It offers S3-compatible API in preview, along with native Azure storage APIs. Supports object lock, versioning, and multiple storage tiers.

## Pricing

Paid. Storage starts at $0.018/GB/mo for hot tier. Egress is $0.087/GB after the 100 GB/mo free allowance.

## Features

- S3-compatible API (preview)
- Four storage tiers
- Object lock / immutable storage
- Versioning
- 100 GB/mo free egress
- Max object size: 4.77 TB
