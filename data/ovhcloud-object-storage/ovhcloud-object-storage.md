## Overview

OVHcloud Object Storage is an EU-headquartered object storage service with full S3 compatibility. It offers object lock and versioning support, with free egress introduced in January 2026. All storage tiers have a 30-day minimum retention policy.

## Pricing

Paid. Storage at $0.007/GB/mo. Egress is free (as of January 2026).

## Features

- Full S3 compatibility
- Object lock
- Versioning
- Free egress
- 30-day minimum retention on all tiers
- Max object size: 5 TB
