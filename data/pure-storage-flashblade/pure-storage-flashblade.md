## Overview

FlashBlade is a modern data storage platform from Pure Storage designed to accelerate AI workloads, secure data, and streamline application development with cloud-like agility on-premises.

## Key Features

- Cloud Integration
- Metadata Search
- Audit Logging
- Replication
- Multi Protocol Access
- Policy Based Retention
- S3 Compatibility
- Global Namespace

## Deployment

FlashBlade is deployed on-premises as an all-flash scale-out storage system.
