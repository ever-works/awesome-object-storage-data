## Overview

BucketDesk turns Amazon S3 buckets into a secure file workspace for teams, eliminating the need for AWS console logins. Files remain in the user's own S3 bucket and connect via a scoped IAM role.

## Key Features

- Password Protection
- Link Sharing
- Link Expiration
- File Preview
- Cost Management
- IAM Integration
- Activity Log
- Role Based Permissions

## Storage Backend

Amazon S3

## Deployment

Cloud (S3-based)
