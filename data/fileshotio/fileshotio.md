## Overview

FileShot.io is a zero-knowledge encrypted file sharing service that uses AES-256-GCM browser-side encryption to encrypt files in-browser before upload.

## Features

- Zero-knowledge encryption
- AES-256-GCM browser-side encryption
- No account required for sender or recipient
- Self-hostable (MIT open-source)
- Unlimited uploads with no file size restrictions

## Pricing

Free tier available with unlimited uploads and no file size restrictions.
