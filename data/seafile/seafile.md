## Overview

Seafile is a private cloud storage and file sharing platform that supports file sync, team discussions, and collaboration. It is designed for teams that need secure file storage with self-hosted or cloud deployment options.

## Deployment

- **Cloud**: Hosted by Seafile, with a free tier offering 1 GB of storage
- **Self-hosted**: Community Edition available as open source under GPLv3; can be deployed on your own infrastructure

## Features

- Private cloud storage with file sync across devices
- Team discussions and collaboration on files
- Public link sharing with access controls
- Self-hosted option for full data ownership
- Open-source Community Edition (GPLv3)

## Pricing

- **Free cloud plan**: 1 GB storage
- **Self-hosted Community Edition**: Free and open source under GPLv3
- Paid plans available for additional cloud storage and enterprise features
