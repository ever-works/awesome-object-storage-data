## Overview

Nebius Object Storage is an EU-based object storage service offered by Nebius, a Yandex Cloud spinoff. It provides full S3 compatibility with object lock and versioning support. Storage is priced at $0.0164/GB/mo with free internal transfer.

## Pricing

Paid. Storage at $0.0164/GB/mo. Egress at $0.01/GB after free internal transfer.

## Features

- Full S3 compatibility
- Object lock
- Versioning
- Free internal transfer
- EU-only regions
- Max object size: 5 TB
