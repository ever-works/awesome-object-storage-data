## Overview

4EVERLAND is an S3-compatible object storage platform that supports AWS S3 APIs, interface operations, CLI, and various upload methods. It allows users to upload and store files from IPFS and Arweave networks.

## Key Features

- AWS S3 API compatibility
- IPFS storage integration
- Arweave storage integration
- CLI and multiple upload methods supported

## Pricing

Free tier for registered users includes:
- 6 GB of IPFS storage
- 300 MB of Arweave storage
- Arweave file uploads smaller than 150 KB are free
