## Overview

lakeFS provides Git for data — data version control for data lakes. It offers branching, tagging, commits, and zero-copy rollbacks for object storage built on S3-compatible backends.

## Key Features

- Git-like version control for data lakes
- Branching and merging for datasets
- Zero-copy rollbacks
- ACID transactions on object storage
- S3-compatible API
- Compatible with any S3-compatible storage backend
