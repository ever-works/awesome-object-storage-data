## Overview

AIStore is a scalable storage solution for AI applications. It is an object storage system designed for AI and machine learning workloads, providing high-performance data access for training and inference pipelines.

## Key Features

- Scalable object storage for AI workloads
- High-performance data access
- Optimized for machine learning training and inference
- S3-compatible API
