## Overview

JuiceFS is a distributed POSIX file system built on top of Redis and S3. It allows object storage (S3) to be mounted as a local file system with full POSIX compatibility.

## Key Features

- POSIX-compatible distributed file system
- Built on Redis for metadata and S3 for data storage
- Mount object storage as local file system
- High performance for distributed workloads
